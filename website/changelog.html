Changelog

Development & Release Log

Complete record of improvements, bug fixes, and additions to Blade Launcher.

v2.4.7-debug Current Build
Added

Offline nickname accounts with immediate local profile creation and skin/cape attachment for singleplayer and LAN worlds.

Added

Custom 3D skin & cape import dialog with direct URL downloader, local file picker, and Alex/Steve arm model selection.

Added

Intelligent GPU renderer suggestion checking device Vulkan capabilities before recommending GL4ES, Zink, or VirGL.

Added

Java 25 runtime download integration in Runtime Manager alongside Java 8, 11, 17, and 21.

Fixed

Fixed Minecraft 26.2+ crash caused by missing GLFW method implementations in native bridge.

Fixed

Eliminated character-by-character vertical text wrapping across Account List and Settings screens.

Changed

Rebranded launcher namespace to com.sednium.bladelauncher and module to BladeLauncher, preserving all original upstream licenses and credits.

Changed

Replaced fixed side navigation rail with bottom navigation bar optimized for portrait mobile screens.

v2.4.0 Upstream Fork
Added

Forked from ZalithLauncher2 — process-isolated JVM runtime, GL4ES/Zink rendering pipeline, and Modrinth/CurseForge downloader foundation.
