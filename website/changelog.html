Changelog

Build log

Blade Launcher hasn't shipped a public build yet — this is the development log, kept honest as the app comes together.

2.4.7-debug In development
Added

Offline (nickname) accounts, alongside Microsoft sign-in — for singleplayer, LAN, and offline-mode servers like Aternos.

Added

Custom skin and cape import, by direct URL or from a local file, with format and dimension validation.

Added

Renderer recommendation: selecting a Minecraft version now checks it against the device's GPU and suggests GL4ES, Zink, or VirGL — never switched automatically.

Added

Java 25 runtime, downloadable per-instance from the Runtime Manager alongside 8, 11, 17, and 21.

Fixed

Minecraft 26.2+ failing to launch with a missing-method crash in the bundled GLFW implementation.

Changed

Rebranded from the upstream ZalithLauncher2 namespace to Blade Launcher, including the app's internal package identity — every upstream credit and license kept intact.

Changed

Settings, version management, and download screens moved from a fixed side rail to a bottom navigation bar, giving content the full screen width on phones.

Changed

About screen now leads with Blade Launcher and Sednium's own credit, ahead of the preserved upstream acknowledgements.

Fixed

Account List, Controls, and several other settings screens no longer wrap long labels one character per line — a width-constraint bug found across multiple shared list components.

Fixed

System status bar was hidden outside of actual gameplay; restored everywhere except the in-game screen.

Base Fork point
Added

Forked from ZalithLauncher2 — process-isolated JVM architecture, Modrinth/CurseForge browsing, and the existing GL4ES/Zink renderer foundation carried over as-is.

Blade Launcher is an unofficial modified version of ZalithLauncher2, developed by Sednium.
