How Blade Launcher works

Everything here reflects the app as it's actually built — not a roadmap.

Java runtimes

Open Settings → Java, and Blade Launcher shows every JRE it can run: 8, 11, 17, 21, and 25. None of them ship inside the app install — each is fetched on demand from the Runtime Manager, so you only download what a given instance actually needs.

Minecraft versionRecommended runtime
1.16 and earlierJava 8
1.17 – 1.20.4Java 17
1.20.5 and laterJava 21
26.1 and laterJava 25

These are recommendations, not requirements — a version can be assigned any installed runtime from its instance settings.

Choosing a renderer

Three rendering backends live under Settings → Renderer:

  • GL4ES — the broadly-compatible default. Works everywhere, including most Adreno GPUs.
  • Vulkan Zink — used automatically for Minecraft 26.2 and later on devices with real Vulkan 1.2 support. Faster where it's supported, but not every GPU qualifies.
  • VirGL — an alternative path for specific driver/device combinations where Zink isn't the better fit.

When you select a Minecraft version, Blade Launcher checks it against your device's actual GPU capabilities and suggests a renderer — it won't switch anything without you confirming. On Adreno hardware, that recommendation stays on GL4ES even for newer versions, since Zink support there is inconsistent.

Accounts

Two account types, for two different situations:

Microsoft account

Required for Realms and any server that verifies ownership — Hypixel and most large public servers included. Sign in from Account List → Add Account.

Offline account

A local nickname, no sign-in. Works for singleplayer, LAN worlds, and servers explicitly running in offline mode — including free hosts like Aternos, when the server owner has set that up. It will not get you into servers that check for a verified purchase, by design.

Either account type can have a custom skin and cape — pasted from a direct image URL, or imported from a file on your device.

Mods & modpacks

The Download tab searches Modrinth and CurseForge directly. Installing a mod resolves its dependencies automatically; installing a modpack sets up matching mods, configs, and the recommended loader in one step.

Once mods are installed, the Mods Updater checks everything in an instance against the latest compatible versions and updates in batch, rather than one mod at a time.

Troubleshooting

A version won't launch after picking a renderer

Switch back to GL4ES from Settings → Renderer for that instance. If Zink was selected on a device without full Vulkan 1.2 support, this is the expected fallback — GL4ES works on effectively every device.

My offline account can't join a server

The server is running in online (verified) mode. This isn't a bug — it's the server's own anti-piracy check, and it requires a signed-in Microsoft account with a purchased copy of the game. It works the same way on every launcher, official or otherwise.

A skin URL is rejected as the wrong size

Blade Launcher expects a direct link to a PNG, not a webpage. Right-click (or long-press) the skin image itself on its source site and copy that direct image address, then paste that.
